# review-release-readiness

Check all required specs merged by human, CI/tests, demo and screenshots, RLS and security invariants, Compose offline operations, optional embedding behavior, Helm readiness, storage adapters, federation security profile, backup restore and known limitations. Report blockers and evidence. No merges or auto-merge.
