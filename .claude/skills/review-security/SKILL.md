# review-security

Review concrete code, migrations, RLS policies, trust authority, public/private visibility, semantic data egress and credentials, cached eligibility, sandbox execution, and negative tests. Record evidence-backed severity and exact reproduction; require fail closed when missing critical facts. Never silently weaken invariant or test to obtain passing state. Do not merge PRs.
