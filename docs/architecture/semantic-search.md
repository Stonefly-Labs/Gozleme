# Semantic search MVP contract

Disabled by default; no embedding model/remote API required to boot. `pgvector` is enabled/configured only for optional semantic indexing. Provider abstraction supports local/offline and explicitly configured remote embeddings; never transmit private description/tool metadata to remote provider without tenant-authorized egress. Store embedding input content version, provider/model identifier, vector dimensions, index generation, scope and status. Asynchronous idempotent jobs; provider outages degrade to lexical search. Public canonical and org-private indexing domains are kept access-safe with RLS/visibility filters and disclosure restrictions. Exact-search correctness baseline; HNSW ANN optional with tenant-aware recall regression tests. Combine lexical/vector ranking without assuming scores are comparable, e.g. reciprocal rank fusion. New model dimensions require separate generation and deliberate reindex; no mixing incompatible vectors.
