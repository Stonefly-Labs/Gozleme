# Domain contract overview

Canonical `RegistryIdentity` → `Publisher` → `Capability` → `ImmutableRevision` → `ChildCapability` and `ProjectionGeneration`. Directed `CapabilityRelationship` edges include declared dependency provenance and optional org-scoped curated overlays. `Organization` has `Membership`, `RoleAssignment`, `ConnectionProfile`, `VisibilityGrant`, `Approval`, `PolicySet`, `Evidence`, `PrivateCatalogOverlay` and `SharingGrant` where appropriate. A `ResolutionPlan` pins exact revision, projection, digest and transitive edge decisions; authorization is revalidated at use time. `FederationSource` tracks scoped cursor, source checkpoint, revocation freshness, key-set version, and quarantine as separate typed states. Artifacts are immutable digest-validated blobs with privacy, lawful deletion and reference accounting; content deduplication never grants visibility. Object lifecycles must never be collapsed into one status field.
