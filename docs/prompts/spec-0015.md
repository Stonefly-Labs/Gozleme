### Implementation alignment (GOZ-0000-IF-05, IF-06, IF-09, IF-13, 2026-11-14)

_Provenance: added by the post-convergence Spec Impact Analyst for GOZ-0000 at commit `e7904ad` (findings in `docs/specs/000-repository-bootstrap/reviews/impact-findings.json`). Roadmap Steward must bump `promptRevision` 1 → 2. These bullets record implemented foundation facts and the obligations they create within confirmed architecture; they do not change scope or security invariants._

- (IF-05) Verified on the GOZ-0000 stack: pgvector 0.8.6 in `pgvector/pgvector:pg17` is not a trusted extension, and `CREATE EXTENSION vector` as `gozleme_migrator` fails ('permission denied … Must be superuser'). EF migrations cannot create it unconditionally. Provide an operator/superuser provisioning step (for example an opt-in script under `deploy/postgres/init/` for Compose and a Helm README prerequisite), and make vector-dependent objects conditional or separately applied so plain `postgres:17-alpine` keeps passing `OptionalVectorTests`. Granting superuser to `gozleme_migrator` or `gozleme_app` is out of authority and requires human approval.
- (IF-05) The status document reports `capabilities.vector.available` (listed in `pg_available_extensions`) and `enabled` (present in `pg_extension`). `enabled` means installed in the database, not that semantic search is configured; expose semantic-search/provider state as a distinct indicator through a contract revision rather than overloading it.
- (IF-06) `GET /api/v1/status` contract v1 (`docs/specs/000-repository-bootstrap/contracts/status-api.openapi.yaml`) has `additionalProperties: false` on `ServiceStatus` and `DependencyStatus`; dependency `status` is `healthy|unavailable`; overall status is `degraded` only when a `required: true` dependency is unhealthy. Report a new dependency as an additional `dependencies[]` entry; optional providers use `required: false` so the base stack never degrades because of them. New fields or status values need a contract revision (OpenAPI, `web/src/lib/status.ts` validator and tests updated together). The web validator accepts `capabilities` as null or an object whose `vector` entry is optional (GOZ-0000-IF-07, corrected in `3273724`); keep that tolerance for non-database dependencies.
- (IF-09) Reuse `tests/Gozleme.Api.IntegrationTests/Infrastructure/GozlemeDatabase.cs` (starts PostgreSQL, applies `01-roles.sh`, runs the real migrator; exposes `SuperuserConnectionString`, `MigratorConnectionString`, `AppConnectionString`) and `GozlemeApiFactory`. `GozlemeDatabase.ScalarAsync` defaults to the superuser connection, which bypasses RLS: isolation and leak tests must use `AppConnectionString` or the API. The assembly-wide `PgvectorDatabaseFixture` database is shared, so mutating tests need isolated data or their own `GozlemeDatabase`. Tenant-safe vector tests must run as `gozleme_app`.
- (IF-13) Deployment conventions: Helm runs containers with `readOnlyRootFilesystem: true` and only `/tmp` (emptyDir) writable; secrets reach pods only through Secrets referenced by name (pattern: `database.existingSecret` with keys `app-connection-string`, `migrator-connection-string`), never chart values. Compose services bind host ports to `127.0.0.1`, take overridable `GOZLEME_*` variables and keep throwaway local defaults in `.env.example`. A local embedding model service, if added, must be optional (for example a Compose profile) so the default stack boots without it.
